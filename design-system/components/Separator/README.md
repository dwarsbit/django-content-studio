# Separator

A thin `border` line between groups, such as the button groups in a toolbar.

- Use it between groups of the same kind; use space, not a line, between sections of a page.
- `orientation="vertical"` inside rows; give the row a height so the line shows.
- Decorative by default; pass `decorative={false}` only when the division means something to screen readers.

The consumer provides the orientation.
