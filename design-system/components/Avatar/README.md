# Avatar

A round picture for a person, tenant or media item, with a fallback while it loads or when there is none.

- `AvatarImage` with an `alt`; `AvatarFallback` with one or two initials.
- 32px by default; change the size with a class, never stretch it.
- In relation displays the admin shows the avatar first, then initials, then an icon.

The consumer provides the image `src` and the fallback initials.
