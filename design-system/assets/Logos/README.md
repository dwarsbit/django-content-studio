# Logos

- `content-studio-icon.svg`: the app icon, a letter D built from six rounded text lines (`color-gray-100`) on a rounded square with a mist gradient from `color-gray-600` to `color-gray-900`. Full color, not single-ink: use it as is, on any ground.
- `content-studio-icon.png`: the same icon at 512 × 512 px, for places that cannot show SVG.

There is no wordmark: next to the icon, set "Django Content Studio" (or "Content Studio" after the first mention) in Inter Variable at weight 600 in `foreground`. Keep clear space of at least a quarter of the icon's width around it, and never recolor, stretch or outline it.
