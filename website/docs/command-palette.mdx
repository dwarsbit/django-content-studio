# ⌨️ Command palette

The command palette is the quickest way around the admin. Press **⌘K** on
macOS or **Ctrl K** on Windows and Linux, or click the search button at the
top of the main menu, and type where you want to go.

## What it offers

- **Navigate** to the dashboard, the media library and every registered
  model the editor may view.
- **Create** a new object of every model the editor may add.
- **Trash**: the trash page of every model with
  [soft delete](/docs/content/registering-models#soft-delete-and-the-trash).
- **Theme**: light, dark or the system setting.
- **Log out**.

The entries filter as you type.

## Search

After two or more characters, the palette also searches the objects
themselves: every registered model with `search_fields`, matched the same way
as on its list page. Results appear grouped by model; picking one opens its
edit page.

```python
# blog/admin.py
from content_studio import register
from content_studio.admin import ModelStudio

from .models import Article


@register(Article)
class ArticleStudio(ModelStudio):
    search_fields = ["title"]  # also searched from the palette
```

The search only covers models the editor may view, only the selected
tenant's objects, and leaves out objects in the trash. It shows at most five
results per model, so one large model cannot crowd out the others; the list
page's own search finds everything.
