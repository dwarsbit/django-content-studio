# ⌨️ Command palette

The command palette is the fast way around the studio: press
**⌘K** (macOS) or **Ctrl K** (Windows/Linux), or click the search
button at the top of the main menu, and jump anywhere.

## What it offers

- **Navigate** — the dashboard, the media library and every registered
  model you may view.
- **Create** — a "new <model>" entry for every model you may add.
- **Trash** — the trash page of every model with
  [soft delete](/docs/content/registering-models#soft-delete-and-the-trash)
  configured.
- **Theme** — switch between light, dark and system.
- **Log out**.

Entries filter as you type.

## Global search

Type two characters or more and the palette also searches the
objects themselves: every registered model with `search_fields` is
searched with the same match its own list view uses, and matches
appear grouped under *Search results*. Picking one opens the object
in the editor.

```python
@register(Article)
class ArticleStudio(ModelStudio):
    search_fields = ["title"]  # searchable from the palette
```

The search respects your permissions (only models you may view are
searched), multi-tenancy (only the current tenant's rows) and soft
delete (trashed objects stay hidden). Results are capped at five per
model so one chatty table cannot drown out the rest — the list view's
own search remains the tool for exhaustive queries.
