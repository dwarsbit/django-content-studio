# 📜 Public API

Content Studio follows [semantic versioning](https://semver.org/) for its
public API: from version 1.0, the names listed on this page change only in
a major release, after a deprecation period with a warning.

The public API consists of:

- the names below, imported from the module they are listed under;
- the documented attributes and methods of `ModelStudio`,
  `InlineModelStudio` and `ContentStudioSite` — the configuration options
  and hooks such as the `has_*_permission` methods, `get_fields`,
  `get_list_item_display`, `get_relation_display`, `get_tenants`,
  `get_thumbnail`, `get_media_serializer_fields` and `crop_image`;
- every [setting](/docs/settings) in the `CONTENT_STUDIO` namespace;
- the [system check](/docs/system-checks) IDs (their message texts may
  change);
- the URLs included with `include("content_studio.urls")` and the
  `content_studio.contrib.password_reset` app, as installable units.

Everything else is internal and may change in any release: the generated
REST backend and its wire format, the serializers, view sets, router,
permissions, filters and search, the login and token backends' internals
(select them by dotted path in the settings), and any name not listed
here — even when it can be imported.

## `content_studio`

The registration decorator and the package version.

- `VERSION`
- `register`

## `content_studio.admin`

Studios, the site and their configuration objects. `admin_site` is the default site.

- `ContentStudioSite`
- `InlineModelStudio`
- `ListItemDisplay`
- `ModelGroup`
- `ModelStudio`
- `RelationDisplay`
- `admin_site`
- `register`

## `content_studio.form`

Edit form layout and table columns.

- `ActivityLog`
- `ButtonLink`
- `Component`
- `Field`
- `FieldLayout`
- `FormSet`
- `FormSetGroup`
- `Link`
- `TableColumn`

## `content_studio.actions`

Custom bulk actions.

- `bulk_action`

## `content_studio.dashboard`

The dashboard and its layout widget. `DashboardWidget` is the base type of the built-in widgets.

- `Dashboard`
- `DashboardWidget`
- `SpacingWidget`

## `content_studio.dashboard.*`

The built-in dashboard widgets, each from its own module.

- `content_studio.dashboard.statistic.StatisticWidget`
- `content_studio.dashboard.content_list.ContentListWidget`
- `content_studio.dashboard.activity_log.ActivityLogWidget`
- `content_studio.dashboard.scheduled_tasks.ScheduledTasksWidget`

## `content_studio.extensions`

Menu links and embedded pages.

- `IFramePage`
- `MainMenuLink`

- `SwitchWidget`
- `TagWidget`
- `TextAreaWidget`
- `TimeWidget`
- `ToggleGroupWidget`
- `URLPathWidget`

Optional abstract base models.

## `content_studio.validators`

- `sanitize_html`
