# ⚙️ Settings reference

All settings live in a single `CONTENT_STUDIO` namespace in your Django
settings. Every option is optional.

```python
CONTENT_STUDIO = {
    "ADMIN_SITE": "content_studio.admin.admin_site",
}
```

## ADMIN_SITE {#admin_site}

The admin site instance to use — import path string. The default site works
out of the box; subclass `AdminSite` to customize the dashboard, extensions,
tenants, thumbnails or media serializer fields and point this setting at your
instance.

## LOGIN_BACKENDS {#login_backends}

Import path strings of login backends. Default:

```python
["content_studio.login_backends.UsernamePasswordBackend"]
```

## LOGIN_THROTTLE_RATE {#login_throttle_rate}

Rate limit for login attempts, per IP, as a DRF rate string — default
`"10/min"`. `None` disables throttling. With the default per-process cache
every worker counts separately; configure a shared cache for the full limit.

## TOKEN_BACKEND {#token_backend}

Import path string of the token backend class that authenticates the admin
API — default `"content_studio.token_backends.JsonWebTokenBackend"`, the
bundled JSON Web Token backend ([authentication](/docs/authentication)).

## TOKEN_LIFETIME {#token_lifetime}

Lifetime of the access token in seconds — default `3600` (one hour). The
browser keeps the access token in memory; a 401 triggers a silent refresh,
so short lifetimes do not log users out.

## REFRESH_TOKEN_LIFETIME {#refresh_token_lifetime}

Lifetime of the refresh token in seconds — default `604800` (seven days).
The refresh token lives in an httpOnly cookie and never reaches JavaScript;
it rotates on every refresh.

## TOKEN_SIGNING_KEY {#token_signing_key}

Signing key for the tokens. Default `None` — falls back to the Django
`SECRET_KEY`. Set a dedicated key if you rotate `SECRET_KEY` independently
of admin sessions.

## TOKEN_ALGORITHM {#token_algorithm}

Algorithm used to sign the tokens (any algorithm PyJWT supports) — default
`"HS256"`.

## EDITED_BY_ATTR / EDITED_AT_ATTR / CREATED_BY_ATTR / CREATED_AT_ATTR {#audit-attrs}

Field names for the audit stamps. Defaults: `"edited_by"`, `"edited_at"`,
`"created_by"`, `"created_at"`. The interface stamps `created_by` on create
and `edited_by` / `edited_at` on update — on models that define those fields
(other models are untouched).

## MEDIA_LIBRARY_MODEL / MEDIA_LIBRARY_FOLDER_MODEL {#media_models}

Import path strings of the media and folder models for the
[media library](/docs/media-library). Both default to `None` — the library is
disabled.

## TENANT_MODEL {#tenant_model}

Import path string of the tenant model for
[multi-tenancy](/docs/multi-tenancy). Default `None` — tenancy is disabled.

## PASSWORD_RESET_EXPIRATION_TIME {#password_reset_expiration_time}

Minutes a password reset code stays valid. Default `10`.
